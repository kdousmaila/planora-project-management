# Planora – Agile Project Management Platform

Planora is a full-stack Agile project management platform that combines classic project management tools (Backlog, User Stories, Sprints, Kanban) with real-time collaboration and AI-powered features for team well-being.

Built as a team project (GLSi-4-D, Tek-Up), **Planora was selected for a faculty Gala competition**.

## Features

- **Agile Project Management** — Product Backlog, User Stories, Tasks/Subtasks, Sprints, Kanban board, sprint history
- **Real-Time Collaboration** — Team messaging with file sharing, pinned messages, notifications, and a contextual AI chatbot
- **Video Conferencing** — Built-in video meetings module
- **Collaborative Calendar** — Shared team agenda and scheduling
- **AI Sentiment Analysis** — Daily check-ins analyzed by AI to track team wellbeing, motivation, and stress
- **Analytics Dashboards** — Visual insights into team health and project progress

## Tech Stack

| Layer | Technology |
|---|---|
| Backend | ASP.NET MVC, C# |
| Frontend | Angular |
| AI Services | Python |
| Database | SQL Server |

## Project Structure

- `Planora` — Main ASP.NET MVC application
- `Planora.Domain` — Domain entities and business logic
- `Planora.Application` — Application/service layer
- `Planora.Infrastructure` — Data access and external services
- `planora-frontend` — Angular frontend
- `planora-ai` — Python AI services (chatbot, sentiment analysis)
